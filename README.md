# Aldrin P. Luis | Portfolio

## Tech Stack

| Technology | Purpose |
| --- | --- |
| Vue 3 | UI framework |
| TypeScript | Type safety |
| Tailwind CSS 4 | Styling, via the `@tailwindcss/vite` plugin |
| Vite | Build tool and dev server |
| vue-tsc | Type checking for Vue files |

Fonts: Figtree, JetBrains Mono, and Syne (Google Fonts).

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Ainnz0/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
